# TF2ItemBrowser
TF2 Item Browser addon for Garry's Mod
https://steamcommunity.com/sharedfiles/filedetails/?id=3841189487

TF2 item schema parser that makes all TF2 items conveniently spawnable in sandbox, with two main uses:
- Find TF2 items using natural language instead of unreliable model names; search for items by display name, class, equip region, and so on.
- Spawn items as props, or select a class ragdoll/animprop/etc. and automatically equip items to it, loadout.tf style.
